# Asset provenance

The rack, bug, and robotic swatter/hand are original procedural Blender models generated by `art/generate.py`. Editable native source: `art/models.blend`. Runtime meshes: `assets/models/*.glb`, merged by material to reduce draw calls. The portal cover is rendered in Blender from these same models. Room geometry and UI are authored in GDScript; no image-generation API was needed.

Music and effects were generated through OpenRouter using `google/lyria-3-clip-preview`, with two 30-second requests at $0.04 each. `tools/asset-spend.json` records the prompts, generation IDs, response usage/cost, and filenames. `music.ogg` is a compressed, faded instrumental loop. `swat.wav`, `hit.wav`, and `clear.wav` are brief cropped samples from the generated electronic sound-design clip; they are placeholders rather than precise Foley recordings. The generator uses ffmpeg for format conversion and cropping. Raw provider output stays in ignored `artifacts/`.

Regenerating audio is a separate, explicit paid action:

```sh
python3 tools/generate_audio.py music
python3 tools/generate_audio.py effects
python3 tools/build.py --game debug
```

Normal setup, builds, gameplay, and releases do not call OpenRouter. No secrets are stored in the game project or browser export.
